# Разбор записей и голосовые профили — MICreactor 1.1.3

В истории выберите готовую расшифровку и нажмите **«Разобрать запись…»**.
Откроется отдельное окно с репликами, проигрывателем и редактором фрагмента.

## Как собрать базу с минимумом ручной работы

1. На вкладке **«Участники»** добавьте имена вручную или импортируйте файл календаря ICS / контакты CSV. Для CSV нужна колонка `Email`, также можно указать `Name`, `Company`, `Aliases`. Поддерживаются русские названия колонок. Совпадения объединяются по почте, а не по похожему имени. Контакт из календаря ещё не доказывает, кому принадлежит голос.
2. Скачайте **модель голоса ReDimNet2 B3** на той же вкладке. Она не заменяет Whisper или модель разделения говорящих.
3. В истории откройте одну знакомую встречу через **«Разобрать запись…»**. Прослушайте реплику, выберите человека и назначьте имя. Для назначения во всём звонке сначала убедитесь, что исходный спикер не объединяет нескольких людей.
4. Нажмите **«Подобрать чистые образцы…»**. Программа предложит фрагменты подтверждённого спикера, отсеяв слишком короткие, тихие, перегруженные и известные наложения речи. Каждый выбранный образец нужно прослушать до конца и вручную отметить как чистую речь одного человека. Проверка сигнала не умеет гарантированно отличить речь от всех видов шума.
5. Сохраните несколько образцов, по возможности из разных встреч и с разных микрофонов. Это эталоны для сравнения, а не переобучение нейросети. Одного хорошего примера достаточно для первых предложений, но условия звонков влияют на точность.
6. На вкладке **«Участники»** нажмите **«Найти участников в готовых записях…»**. После подтверждения количества записей начнётся проверка готовых расшифровок без повторного запуска Whisper. Записи с запретом распознавания и уже применёнными именами Яндекса пропускаются. Кнопка **«Остановить поиск»** сохраняет результаты завершённых записей; при новой записи поиск приостанавливается, если включена соответствующая настройка.

В настройках **«Искать знакомые голоса после распознавания»** включает этот этап для новых расшифровок. Он работает только при наличии модели и образцов. Автоматически сопоставляются раздельные спикеры вида «Участник 1»; смешанный «Участник» без разделения, ваше имя и явно заданные имена не заменяются.

Имя попадает в автоматический экспорт только при сильном совпадении нескольких разных реплик без конкурирующих кандидатов. Это всё ещё предположение, а не подтверждённый факт. В разборе записи оно отмечено **«Автоимя · проверить»**. Для спорного совпадения доступны **«Принять предложенное имя»** и **«Отклонить предложение»**. После сохранения отклонённое предложение не возвращается при повторной автоматической проверке. Предполагаемые имена никогда не пополняют базу образцов сами.

На вкладке **«Участники»** можно искать по имени, почте, компании и другим именам, редактировать карточку, слушать/удалять образцы и объединять дубли. Колонка «Встречи с образцами» считает только встречи, из которых сохранены эталоны, а не все появления человека в архиве. Объединение не переписывает прошлые расшифровки. Удаление профиля удаляет его копии образцов, но не исходные встречи.

## Ручной разбор записи

1. Прослушайте реплику. Перемотка доступна на шкале; переход между репликами — кнопками или Alt+←/Alt+→. Пробел в таблице управляет воспроизведением.
2. Исправьте текст и границы. Если в реплике два человека, разделите её на нужной отметке и проверьте текст обеих частей: он делится приблизительно.
3. Создайте профиль человека или выберите существующий и нажмите **«Назначить»** для одной реплики. Кнопка **«Назначить во всём звонке»** применяет имя ко всем репликам этого исходного спикера на всех дорожках, включая скрытые фильтром. Исключённые фрагменты и подтверждённые имена других людей сохраняются. Затем сохраните правки.
4. Для образца выберите 3–30 секунд чистой речи, желательно 10–30 секунд. Подтвердите, что говорит один человек, и нажмите **«Добавить образец голоса»**. Шумные фрагменты и одновременную речь не добавляйте.
5. В другой записи нажмите **«Предложить имена»**. Проверьте совпадения и подтвердите подходящие. Сходство голоса не является процентом достоверности; слабое или неоднозначное совпадение не получает имени.
6. Нажмите **«Сохранить правки»**. Исходные `transcript.*` останутся прежними; результат появится в `reviewed.md`, `.txt`, `.srt`, `.json`, а разметка — в `speaker-review.json`.

**«Профили…»** позволяет переименовать человека, прослушать сохранённые образцы и удалить ошибочный. Это сохранение эталонов голоса, а не переобучение Whisper. Несколько подтверждённых образцов с разных встреч полезнее повторного добавления одного фрагмента.

Профили и самостоятельные WAV-образцы находятся в `%LOCALAPPDATA%\MICreactor\SpeakerProfiles`. Они сохраняются после удаления исходной встречи. ReDimNet2 B3 загружается один раз (около 18 МБ) и работает локально на CPU; открытие окна не загружает нейросеть в видеопамять.

Для автоматического разделения смешанной записи нужны веса pyannote Community-1: на вкладке **«Модели»** скачайте «Разделение говорящих», затем включите **«Разделять удалённых участников»** в настройках. Hugging Face требует принять условия модели и предоставить токен чтения только для скачивания. Без этих весов доступны ручной разбор готовой расшифровки и работа с голосовыми профилями.

Для WebM без индекса перемотки сначала создаётся локальная WAV-копия в `%LOCALAPPDATA%\MICreactor\ReviewAudio`. Это однократная подготовка; исходное видео остаётся прежним. У старых записей с несколькими дорожками по умолчанию воспроизводится общий фрагмент со всех дорожек; пустые дорожки пропускаются. Для сохранения образца голоса выберите конкретную дорожку.
