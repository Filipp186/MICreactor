# Публикация MICreactor

В публичном репозитории хранятся README, пользовательские инструкции, лицензии,
релизноуты и проверки публикации. Рабочие выгрузки, аудио, скриншоты, настройки,
локальные сборки и журналы хранятся вне списка разрешённых файлов Git.

В каждом рабочем клоне включите проверки один раз. Для них нужен Python 3.

```powershell
git config --local core.hooksPath .githooks
git config --local status.showUntrackedFiles normal
```

Перед отправкой Git проверяет состав файлов, признаки секретов, локальные пути,
адреса и метаданные коммитов. Для автора и коммитера используйте адрес GitHub
`noreply`. Публикуйте ветку `main` и лёгкие теги вида `v1.2.3` обычным `git push`.

Файлы в GitHub Releases загружаются отдельно, поэтому проверки Git на них не
срабатывают. Перед загрузкой распакуйте установщик и проверьте его содержимое,
включая вложенные архивы, метаданные и скомпилированные модули. Создайте черновик
релиза, загрузите проверенный установщик и сравните SHA-256 на GitHub с локальным
файлом. После проверки опубликуйте релиз. Загружайте файлы по одному, указывая их
полные имена, без шаблонов и целых каталогов.
