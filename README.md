# MICreactor 1.0.0

MICreactor — приложение для записи встреч и локальной расшифровки русской и
английской речи на компьютерах с Windows.

## Скачать

[Скачать MICreactor 1.0.0 для Windows](https://github.com/Filipp186/MICreactor/releases/latest)

В разделе загрузки выберите файл `MICreactor-1.0.0-Setup.exe`.

## Системные требования

- Windows 10 или Windows 11, 64-разрядная версия;
- от 8 ГБ оперативной памяти;
- подключение к интернету для первоначальной загрузки моделей;
- видеокарта NVIDIA необязательна, но значительно ускоряет сильные модели.

## Установка

1. Скачайте и запустите установщик.
2. Выберите установку только для себя или для всех пользователей компьютера.
3. После установки запустите MICreactor из меню «Пуск» или с рабочего стола.

## Первый запуск

Откройте вкладку **Модели**. У каждой модели есть собственная кнопка **Скачать**,
а также указаны размер и состояние загрузки.

| Модель | Примерный размер | Назначение |
|---|---:|---|
| Small | 0,5 ГБ | Быстрая черновая расшифровка |
| Medium | 1,5 ГБ | Рекомендуемый баланс качества и скорости |
| Turbo | 1,6 ГБ | Высокая скорость и качество, особенно на NVIDIA |
| Large v3 | 3,1 ГБ | Максимальное качество; на CPU работает медленно |

После загрузки модели распознавание выполняется локально без интернета. Токен для
обычных моделей Whisper не нужен.

## Запись встречи

1. На вкладке **Запись встречи** отметьте нужные микрофоны и системные выходы.
2. Выберите установленную модель.
3. Нажмите **Начать запись** или используйте `Ctrl+Shift+F9`.
4. После остановки откройте вкладку **История**, чтобы запустить анализ, выбрать
   другую модель или открыть готовую расшифровку.

Запись можно ставить на паузу. При аварийном завершении приложения уже записанные
фрагменты сохраняются. Звук записывается отдельными сжатыми дорожками OGG/Opus
для входов и выходов, поэтому длительные встречи занимают значительно меньше
места. Выбор источников можно менять прямо во время записи.

В настройках можно указать своё имя: оно будет использоваться в расшифровке
вместо подписи «Я». Для разделения остальных участников скачайте модель
диаризации на вкладке **Модели**.

При обработке отдельного файла отображаются процент, прошедшее и оставшееся
время. Анализ можно поставить на паузу, продолжить или остановить.

## Где хранятся данные

По умолчанию записи, расшифровки и журналы находятся в папке
`Документы\MICreactor`. Путь можно изменить в настройках.

Аудиозаписи и расшифровки не отправляются в облако.
